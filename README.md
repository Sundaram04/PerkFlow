# PerkFlow

PerkFlow is a fintech-inspired rewards platform project. This repository currently contains the initial Spring Boot foundation only.

## Requirements

- Java 21
- Maven Wrapper (included)

## Build and run on Windows

```powershell
.\mvnw.cmd clean package
.\mvnw.cmd spring-boot:run
```

The application listens on port 8080. No business endpoints or persistence have been added yet.
